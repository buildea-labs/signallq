## Regras de Qualidade

- **Double-Check de Linter:** É obrigatório rodar `npm run lint` localmente e garantir que o resultado seja exatos **0 warnings e 0 erros** *ANTES* de executar `gh pr create`. Se houver erros, resolva-os localmente primeiro.
- **Evidências:** Sempre forneça no PR as evidências de que o linter e o build passaram com sucesso.
